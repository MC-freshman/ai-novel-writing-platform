# AI小说创作平台

一个面向长篇小说创作的 Windows 桌面软件，支持富文档写作、本地知识库检索、AI 对话、角色卡片和世界观资料整理。

## 下载

请到 GitHub Release 页面下载最新版：

- [AI小说创作平台 Releases](https://github.com/MC-freshman/ai-novel-writing-platform/releases)

下载发布压缩包后解压，双击 `打开AI小说创作平台_新版.bat`，或直接运行 `release/AI小说创作平台 0.3.1.exe`。

> 当前 Windows 可执行文件未做代码签名，首次运行时系统可能出现安全提醒。请只从本仓库 Release 页面下载。

## 主要功能

- 富文档写作：标题、正文、粗体、斜体、下划线、引用、列表、对齐、撤销/重做、表格插入。
- Word 文档导入：支持一次选择多个 `.docx`、`.txt`、`.md` 文件，导入 `.docx` 后尽量保留图片、表格和标题结构；可从目录树分组旁直接导入到指定分组。
- 可折叠目录树：章节、文档、小标题可分级折叠；小标题可升降级，文档可直接拖动到分组标题或其他文档上完成分类和排序。
- Word/语雀式编辑体验：正文标题旁支持折叠/展开，适合长大纲和长章节整理。
- 本地知识库：保存或导入内容后自动建立索引，并生成文档、分组、全书三级摘要；每次 AI 检索前会快速核对文件与索引，只更新本次相关的过期资料，并明确列出暂未读取的资料。
- 知识库整理：可把导入文档标记为大纲、正文、补充材料，并调整所属目录，分类会同步到目录树。
- 右侧 AI 助手：提供“对话”和“创作参谋”两个页签，提问时会显示检索阶段和命中范围；流式回答可手动停止，停止或连接中断时保留已生成内容，意外关闭后可恢复生成断点。
- 创作 Agent：会按目标自动选择章节规划、剧情因果、人物发展、伏笔、节奏、连续性、设定核验和安全修订工具；分析范围可自动推荐或手动选择当前章节、当前分卷、全书。执行前显示资料范围、预计 Token 与权限，每个阶段都有可恢复检查点；任何权限都不会直接覆盖正文。
- 创作状态中心：在右侧 AI 标题栏打开“创作状态”，集中管理有原文证据的剧情事实、角色位置/目标/知情/持有物、伏笔生命周期和下一章筹备板；支持按分卷、文档、状态筛选，人工新增和编辑记录，AI 候选仍需作者确认。
- 创作工作台：在“创作状态”弹窗内集中管理章节场景、剧情因果、角色弧线、安全修订、正文批注、分层项目记忆、章节质量诊断和项目交换，不新增左侧导航入口。
- 安全修订与批注：选中正文后可从右键菜单生成修订候选或添加批注，正文旁会显示可点击标记。修订支持整体或逐句采纳，采纳前校验正文位置并自动保存历史版本；冲突时停止写入。批注独立保存并提示原文是否已变化。
- 章节数据保护：每章拥有独立的撤销/重做历史，快速切章会丢弃迟到的加载结果，保存按项目排队并使用原子替换；当一次保存准备把整章变成另一章的相同长文本时会直接停止，避免跨章节误覆盖。
- 分层项目记忆：作者可保存全书、分卷和章节记忆；创作参谋会按当前章节自动选用，避免每次重复说明其他章节的局部约束。
- 剧情规划与诊断：场景可按目标、冲突、转折、结果拆解并拖动排序；因果、伏笔、人物弧线和势力可在统一剧情图中筛选、缩放、拖动和编辑连线；创作统计保存节奏、视角、角色密度、伏笔回收及历次诊断对比。
- 后台任务中心：全书剧情整理、创作 Agent、AI 深度分析、知识库重建和项目快照在后台依次运行，可暂停、继续、停止和重试，并保留已经收到的 AI 部分输出和用量估算；Agent 的失败工具可单独重试，软件异常关闭后未完成任务会标记为可重试。
- 覆盖优先检索：首轮按综合相关度筛选，第二轮只为遗漏的子问题、人物、地点、时间和分卷补充证据；检索详情显示首轮/补证数量、证据置信度和仍缺证据的目标。
- 维护诊断：知识库整理页可查看分卷缓存、索引新鲜度、过期资料、中断 Agent 和失效任务引用，并一键修复索引与缓存元数据。
- 快照与创作分支：项目快照按内容哈希去重，支持比较、改名、安全删除和无引用数据清理；恢复前会自动创建安全快照。实验分支可切换和删除，被分支使用的快照、主线及当前分支均受保护。
- AI 资料生成：可从大纲生成角色卡片、世界观条目，并可提取地点、势力、物品资料，直接写入对应界面。
- 分类管理：角色卡片和世界观条目支持多级分类折叠，例如 `阵营/主角团`、`世界/地理`，并可拖动到其他分类中。
- 分析工作台：支持全局搜索、AI/本地时间线、可缩放关系网、设定一致性检查和章节版本对比；切换页面后会保留上次分析结果。
- 关系和设定管理：关系图可按角色分类和搜索筛选角色、添加关系类型，并在连线上显示关系；一致性检查可限定审查章节和参考资料，问题可标记确认、忽略、修复；地点/势力/物品提取先生成候选再勾选写入。
- 进度与整理：批量导入和重建知识库显示进度；目录树、角色卡、世界观拖动时显示移动目标。
- 试验功能：人物出场统计、地点/势力版图、素材库集中在“分析 / 导出/提取 / 试验功能”中。
- 导出、备份与交换：当前文档可单独导出；全书按目录树逐篇导出，每章正文、每份大纲和每份材料分别生成一个 `.docx`，并可选择是否附带角色卡和世界观资料。DOCX 会尽量保留批注、修订、表格宽度、图片尺寸与位置、标题层级。项目交换包可设密码并选择导入正文、角色卡、世界观、素材或分析数据；交换包明确排除 API 设置、密钥、向量库、历史备份和本机导入路径。

## 隐私与数据

软件默认把小说项目保存在本机“文档/AI小说创作平台/默认小说项目”目录下。项目目录通常包含：

- 正文和导入文档
- 角色卡片
- 世界观资料
- 本地向量索引
- 备份文件
- API 设置

这些本地项目数据不会包含在本仓库源码和 Release 发布包里。

API 密钥只在软件设置中填写。Windows 正式版会把聊天密钥和向量密钥保存到 Windows 凭据管理器，项目配置只保留凭据引用；旧项目中的兼容密钥在下次保存设置时会迁移。请不要把自己的项目目录、向量库或备份文件上传到公开仓库。

设置中的“发布、密钥与软件更新”可查看密钥保存状态、手动检查 GitHub 新版本和运行发布隐私扫描。软件只在你确认后下载或打开更新程序，不会静默安装。

## 模型接口

软件支持 DeepSeek、通义千问 / Qwen、OpenAI、Kimi、Claude、Ollama 和自定义 OpenAI 兼容接口。

DeepSeek 示例：

- 接口提供商：DeepSeek
- 接口地址：`https://api.deepseek.com/v1`
- 聊天模型：`deepseek-chat`
- 接口密钥：填入你自己的 DeepSeek API Key

通义千问示例：

- 接口提供商：通义千问 / Qwen
- 接口地址：`https://dashscope.aliyuncs.com/compatible-mode/v1`
- 聊天模型：`qwen-plus`
- 接口密钥：填入你自己的通义千问 API Key

如果没有配置聊天接口，软件仍可进行本地写作、导入、保存和知识库索引；AI 回答需要配置可用接口。

设置里的“候选扫描上限”和“发送片段上限”是两级限制，不代表每次都会全部发送给 AI。候选最多可扫描 50000 个片段，发送最多 1000 个片段；软件会自动拆分复杂问题，先按综合相关度筛选，再为遗漏的证据目标执行第二轮补读，并在检索详情中解释分卷覆盖、入选原因和证据置信度。聊天默认不因本地固定等待时间而截断，长请求也可手动停止并保留已收到的内容。

长篇项目的向量索引按文档分片保存。普通问答先根据全书、分组和文档摘要路由，再读取需要的分片；全书分析仍会扩大覆盖范围。500 万字合成回归测试包含 250 份文档和 12500 个片段，普通检索只加载路由后的分片，单章保存不会重写其他文档索引。

## 开发运行

```powershell
npm install
npm run start
```

重新打包 Windows 版本：

```powershell
npm run dist
```

打包结果会生成在 `release/` 目录。

更新后执行完整自动回归：

```powershell
npm run test:regression
npm run test:ui-visual
npm run test:long-project
```
