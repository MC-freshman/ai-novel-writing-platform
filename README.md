# AI小说创作平台

一个面向长篇小说创作的 Windows 桌面软件，支持富文档写作、本地知识库检索、AI 对话、角色卡片和世界观资料整理。

## 下载

请到 GitHub Release 页面下载最新版：

- [AI小说创作平台 v0.1.17](https://github.com/MC-freshman/ai-novel-writing-platform/releases/tag/v0.1.17)

下载 `AI-Novel-Platform-0.1.17-clean-package.zip` 后解压，双击 `打开AI小说创作平台_新版.bat`，或直接运行 `release/AI小说创作平台 0.1.17.exe`。

## 主要功能

- 富文档写作：标题、正文、粗体、斜体、下划线、引用、列表、对齐、撤销/重做、表格插入。
- Word 文档导入：支持一次选择多个 `.docx`、`.txt`、`.md` 文件，导入 `.docx` 后尽量保留图片、表格和标题结构；可从目录树分组旁直接导入到指定分组。
- 可折叠目录树：章节、文档、小标题可分级折叠；小标题可升降级，文档可直接拖动到分组标题或其他文档上完成分类和排序。
- Word/语雀式编辑体验：正文标题旁支持折叠/展开，适合长大纲和长章节整理。
- 本地知识库：保存或导入内容后自动建立本地检索索引。
- 知识库整理：可把导入文档标记为大纲、正文、补充材料，并调整所属目录，分类会同步到目录树。
- AI 对话：提问时先检索本地小说资料，再调用已配置的大模型接口回答；支持项目内最近 10 个 AI 会话和项目 AI 记忆。
- AI 资料生成：可从大纲生成角色卡片、世界观条目，并可提取地点、势力、物品资料，直接写入对应界面。
- 分类管理：角色卡片和世界观条目支持多级分类折叠，例如 `阵营/主角团`、`世界/地理`，并可拖动到其他分类中。
- 分析工作台：支持全局搜索、AI/本地时间线、可缩放关系网、设定一致性检查和章节版本对比；切换页面后会保留上次分析结果。
- 关系和设定管理：关系图可按角色分类和搜索筛选角色、添加关系类型，并在连线上显示关系；一致性检查可限定审查章节和参考资料，问题可标记确认、忽略、修复；地点/势力/物品提取先生成候选再勾选写入。
- 进度与整理：批量导入和重建知识库显示进度；目录树、角色卡、世界观拖动时显示移动目标。
- 试验功能：人物出场统计、地点/势力版图、素材库集中在“分析 / 导出/提取 / 试验功能”中。
- 导出与备份：当前章节和整本小说都可导出为 `.docx`，整书导出可选择附带大纲、角色卡和世界观资料，项目可导出 ZIP 备份。

## 隐私与数据

软件默认把小说项目保存在本机“文档/AI小说创作平台/默认小说项目”目录下。项目目录通常包含：

- 正文和导入文档
- 角色卡片
- 世界观资料
- 本地向量索引
- 备份文件
- API 设置

这些本地项目数据不会包含在本仓库源码和 Release 发布包里。

API 密钥只在软件设置中填写，并保存在你本机的项目配置里。当前实现使用 Base64 存储密钥，这只是避免明文直接显示，不等同于加密保险箱。请不要把自己的 `novel.config.json`、项目目录、向量库或备份文件上传到公开仓库。

## 模型接口

软件支持 DeepSeek、OpenAI、Kimi、Claude、Ollama 和自定义 OpenAI 兼容接口。

DeepSeek 示例：

- 接口提供商：DeepSeek
- 接口地址：`https://api.deepseek.com/v1`
- 聊天模型：`deepseek-chat`
- 接口密钥：填入你自己的 DeepSeek API Key

如果没有配置聊天接口，软件仍可进行本地写作、导入、保存和知识库索引；AI 回答需要配置可用接口。

设置里的“检索片段上限”只是最多候选数，不代表每次都会全部发送给 AI。软件会先按上限取候选，再按相关度和上下文字数预算裁剪，尽量减少不必要的 token 消耗。

## 开发运行

```powershell
npm install
npm run start
```

重新打包 Windows 版本：

```powershell
npm run dist
```

打包结果会生成在 `release/` 目录。

## 不要提交的内容

本仓库的 `.gitignore` 已默认排除以下内容：

- `node_modules/`
- `dist/`
- `release/`
- `发布包/`
- `.private/`
- `novel.config.json`
- `chapters/`
- `characters/`
- `worldbuilding/`
- `vector_db/`
- `backups/`
- `analysis/`
- `materials/`
- `.env` 和常见密钥文件

公开仓库前请再次确认没有小说正文、API 密钥、个人资料或未授权素材。
