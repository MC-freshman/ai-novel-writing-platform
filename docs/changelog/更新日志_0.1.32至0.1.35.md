# AI小说创作平台 0.1.32 至 0.1.35 更新日志

## 0.1.32 创作状态人工维护

- 剧情事实、角色状态和伏笔支持按分卷、文档、状态和关键词筛选。
- 支持人工新增剧情事实和伏笔，并可编辑内容、回收计划和作者备注。
- 自动识别条目只能“忽略”或“废弃”，仅人工条目允许直接删除，防止误删分析依据。
- 作者确认、备注和手工修正会在重新分析后保留；人工记录不会因正文修订被误判为失效。
- 缺失或过期的章节可一键转入后台增量更新。
- 下一章筹备板支持新增自定义项目。

## 0.1.33 创作参谋联动

- 右侧创作参谋可勾选剧情事实、角色状态和伏笔作为明确依据。
- 指定依据会优先进入 Agent 上下文，并随分析状态保存在当前项目中。
- 参谋建议可一键加入下一章筹备板，也可继续保存为素材。
- 加入筹备板的建议会保留来源证据，可从筹备板返回关联章节。
- 参谋只提供分析和可改造建议，不会未经确认直接改写正文。

## 0.1.34 快照与任务维护

- 项目快照支持改名和安全删除。
- 被任一创作分支引用的快照禁止删除。
- 支持删除非主线、非当前的实验分支；主线和当前分支始终受保护。
- 支持清理不再被任何快照引用的数据对象，并显示释放空间。
- 后台任务中心支持一键清理已结束的历史记录，运行中任务不受影响。

## 0.1.35 长篇性能与界面收尾

- 剧情事实、角色状态和伏笔改为每批 100 条增量显示，适配超长篇项目。
- 创作状态最多覆盖 500 份目录文档，满足 500 万字测试项目的章节规模。
- 章节修订值和剧情账本增加文件级缓存，重复筛选不再反复读取全部正文和账本内容。
- 增加筛选请求防串线保护，快速输入搜索词时旧请求不会覆盖新结果。
- 创作状态、参谋依据、快照管理和任务历史收进原有弹窗/折叠区，不新增左侧导航入口。
- 完成普通窗口、窄窗口、按钮入口、数据保护、逐篇 Word 导出和 500 万字性能回归。

## 数据兼容

- 本次更新不会打包或迁移 API 密钥、默认小说项目、正文、角色卡、世界观或向量库。
- 旧项目首次打开时会自动补齐新版创作状态文件；原有章节和知识库目录保持不变。
- 更新前备份已保存在工作区外的本机备份目录中。
