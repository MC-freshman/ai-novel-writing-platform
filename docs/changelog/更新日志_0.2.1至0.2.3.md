# AI小说创作平台 0.2.1 至 0.2.3 更新日志

## 0.2.1 稳定性与恢复

- 新增项目操作记录、异常会话识别、章节恢复草稿和窗口状态恢复。
- 项目结构升级前自动创建快照和配置备份，失败时自动回滚。
- 项目健康检查新增迁移状态、中断操作、目录顺序和失效工作区引用检查。

## 0.2.2 长篇分层检索

- 复杂问题会自动拆成多个检索子问题。
- 综合语义、关键词、人物/地点/时间、相邻章节、剧情事实、伏笔、因果和分层摘要评分。
- 全书任务按全书、分卷、文档、原始片段四层读取，支持分卷检索缓存。
- 检索详情新增分卷覆盖、正文原文覆盖、资料入选原因和覆盖警告。

## 0.2.3 小说创作 Agent

- 新增章节规划、剧情因果、人物发展、伏笔、节奏、连续性、设定核验和安全修订八类工具，并按作者目标自动选择。
- 新增只读分析、可创建规划、可生成修订候选三级权限；任何权限都不能直接覆盖正文。
- Agent 转为后台连续工作流，每个工具完成后立即保存阶段结果。
- 后台任务支持暂停、继续、停止和重试；异常退出后可恢复，失败工具可单独重试。
- 保持右侧 AI 区和现有任务中心布局，不新增主导航入口。
