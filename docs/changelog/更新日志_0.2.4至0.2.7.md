# AI小说创作平台 0.2.4 至 0.2.7 更新日志

## 0.2.4 知识库新鲜度

- 新增文件签名与内容哈希缓存，未变化的文档无需重复计算全文哈希。
- AI 检索前自动检查索引，只更新本次问题需要的过期资料。
- 检索诊断显示过期资料、自动更新数量和延后处理数量，不再把未读资料误报为不存在。

## 0.2.5 覆盖优先检索

- 首轮继续综合语义、关键词、实体、相邻章节、剧情事实、伏笔和因果关系排序。
- 第二轮只为首轮遗漏的子问题、人物、地点、时间、分卷或指定资料补充原始证据。
- 检索详情新增首轮/补证数量、证据置信度、第二轮补读来源和仍缺证据目标。

## 0.2.6 Agent 范围与检查点

- 创作 Agent 支持自动推荐、当前章节、当前分卷和全书分析范围，作者可手动覆盖推荐。
- Agent 工具按所选范围检查人物、节奏、设定和一致性。
- 每个工具与最终汇总阶段保存等待、运行、完成、失败、跳过检查点，切换页面后仍可查看。

## 0.2.7 维护诊断与发布整理

- 知识库整理页新增紧凑维护诊断，显示向量索引、分卷缓存、新鲜度缓存、中断 Agent 和失效引用。
- 新增“修复索引与缓存”，统一补齐过期资料、移除孤立索引、刷新检索缓存并修正失联 Agent 状态。
- 更新中文使用说明、完整测试方案、启动器和发布版本号。
- 新增新鲜度、二次补证、Agent 范围和维护诊断自动回归测试，测试不调用付费模型接口。
