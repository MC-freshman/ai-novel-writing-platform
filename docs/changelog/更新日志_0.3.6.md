# 0.3.6 · 安静的写作空间

这次更新让正文回到界面中心：日间以暖纸色、鼠尾草绿为主，夜间改为低亮度的森林绿；采用本机中文衬线字体和舒展的段落间距。

- 首次打开使用 256 px 目录和 360 px 助手，为正文留出更宽空间；已经保存的侧栏宽度继续沿用。
- 左侧导航保留图标和名称，章节选择有明显标记；保存动作与其他项目工具形成清晰层级。
- 右上角“专注写作”隐藏两侧面板、章节进度和多余统计，保留保存、当前字数、AI 入口和明确的退出按钮。
- 编辑章节时按 `Ctrl+Shift+F` 切换专注，按 `Esc` 返回；原有 `F11` 入口仍可用。
- 章节进度默认收起，点击底部章节进度条可展开任务和状态操作；已保存的展开偏好继续沿用。
- AI 输入框有持续可见的标签和发送快捷键。空态示例先填入问题，作者可修改后发送。
- 增加正文和章节字段的可访问名称、键盘焦点样式；尊重系统“减少动画”设置。

从 `打开AI小说创作平台_新版.bat` 启动本地新版，打开原来的小说项目，选择一章即可开始写作。顶部月亮/太阳按钮切换日夜主题；字号与行距仍可在设置中调整。
