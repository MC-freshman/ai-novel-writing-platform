# 服务测试覆盖登记

2026-10-11登记。基线40模块，本轮增加project-transactions后为41模块。专门服务套件从4份22用例扩至9份112用例（62个专门用例及50个复用的服务/IPC契约用例），同时复用既有直接服务与集成回归。下表列出证据入口，不代表每个模块100%分支覆盖。实际覆盖率由`npm run test:services:coverage`测量，`npm run check:services`防止新模块漏登记。
