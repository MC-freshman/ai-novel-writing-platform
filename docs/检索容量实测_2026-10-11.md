# 检索容量实测（2026-10-11）

命令：`npm run bench:capacity`。每组用独立Node进程和隔离合成项目；384维为本地向量，1024维为合成API格式向量，不调用模型账户。

设备：AMD Ryzen 7 8845HS w/ Radeon 780M Graphics     ；物理内存 23.3 GiB；Node v24.18.0。每片段文本560字，1000片段一个来源，每组热检索15次。冷检索指新进程首次装载和扫描，未清空操作系统文件缓存；不等同物理冷盘。内存峰值包含生成、装载、检索和失效检查。

本机单项目20万片段已完成上述检查。1024维首次检索约28秒、峰值约1.69 GiB，应考虑首次装载等待和内存预算。这是已测可用规模，不是已证明的最大容量；更大规模、同时缓存多个大项目、其他维度、完整Electron进程和真实小说检索质量未由本基准证明。

磁盘格式仍为v3分片；未以此次测量新增20万硬上限。原始JSON保存在本轮本地验收目录，合成索引已由各组worker清理。
